# ConcreteGAN: Physics-Aware Prediction and Inverse Design of Concrete Strength

Проект посвящён прогнозированию прочности бетонной смеси с использованием физически обоснованных моделей машинного обучения. Основная задача — предсказать прочность бетона на сжатие по составу смеси, возрасту образца и дополнительным инженерным признакам.

В работе сравниваются классические модели машинного обучения, нейросетевые подходы, физически ограниченный генератор, GAN-подход, NEAT+BNN-дискриминатор, ансамбли, conformal prediction и inverse design для подбора состава бетонной смеси под целевую прочность.

## Цель проекта

Цель проекта — построить модель, которая способна:

- прогнозировать прочность бетона на сжатие;
- учитывать физические закономерности твердения бетона;
- оценивать неопределённость прогноза;
- работать устойчиво на малых выборках;
- проверять поведение модели при экстраполяции по возрасту;
- подбирать состав бетонной смеси под заданную целевую прочность.

## Используемые данные

В проекте используется архив `Concrete.zip`, содержащий несколько источников данных:

- `Normal_Concrete_DB.csv` — основной корпус данных по рецептам бетонных смесей;
- `boxcrete_data.csv` — лабораторная выборка рецептов;
- `synthetic_training_data.csv` — синтетический набор для тестирования;
- `ГОСТы.csv` — нормативные диапазоны прочности по классам бетона;
- `materialgen/` — пакет с реализациями NEAT и BNN;
- `examples/` — примеры запуска компонентов `materialgen`.

Основной целевой признак — прочность бетона на сжатие, выраженная в МПа.

## Что реализовано в ноутбуке

### 1. Загрузка и подготовка данных

На первом этапе выполняется загрузка данных, приведение русскоязычных колонок к единой схеме, обработка числовых значений, объединение разных источников и подготовка признаков.

Так как один и тот же рецепт может встречаться при разных возрастах образца, разбиение на обучающую, валидационную и тестовую выборки выполняется по `recipe_id`. Это снижает риск утечки данных между выборками.

### 2. Разведочный анализ данных

В ноутбуке проводится анализ распределений признаков, корреляций и физических зависимостей. Отдельно проверяются:

- зависимость прочности от возраста;
- связь прочности с водоцементным отношением;
- применимость логарифмической зависимости набора прочности;
- соответствие данных инженерным ограничениям.

### 3. Физические признаки

Для повышения качества моделей добавляются производные признаки:

- водоцементное отношение;
- водовяжущее отношение;
- доля цементного теста;
- доля заполнителей;
- доля мелкого заполнителя;
- логарифм возраста;
- оценка плотности смеси;
- признаки, связанные с нормативными диапазонами прочности.

Эти признаки помогают модели учитывать инженерную структуру задачи, а не работать только с исходными табличными значениями.

### 4. Базовые модели

В качестве ориентиров используются классические модели машинного обучения:

- Linear Regression;
- Ridge Regression;
- Random Forest;
- LightGBM;
- MLP;
- Bayesian MLP.

Базовые модели нужны для сравнения с более сложными физически обоснованными подходами.

### 5. Физически обоснованный генератор

В проекте реализован генератор `PhysicalGenerator`, который предсказывает прочность по формуле:

```text
strength(t, x) = a(x) + b(x) * log(1 + t)
```

Здесь `x` — признаки состава смеси, `t` — возраст образца, а коэффициент `b(x)` ограничен снизу через `softplus`. Благодаря этому модель архитектурно сохраняет физически ожидаемое свойство: прочность бетона не должна уменьшаться с увеличением возраста.

### 6. NEAT+BNN-дискриминатор

Для дискриминатора используется связка NEAT и Bayesian Neural Network из пакета `materialgen`.

NEAT подбирает структуру нейросети, а BNN позволяет оценивать неопределённость прогноза. В проекте сравниваются несколько вариантов NEAT-подхода:

- `bneatest`;
- `neatest`;
- `python-neat`.

Лучший вариант используется как дискриминатор в GAN-цикле.

### 7. GAN-обучение с физическим loss

В ноутбуке реализован GAN-подход, где генератор обучается не только по ошибке прогноза, но и с учётом дополнительных ограничений:

- adversarial loss от дискриминатора;
- физический штраф по закону Абрамса;
- штраф за выход за нормативные диапазоны ГОСТ;
- встроенная монотонность прочности по возрасту.

Итоговая функция потерь объединяет ошибку данных, adversarial-компонент и физические ограничения.

### 8. Калибровка неопределённости

Для моделей, которые возвращают не только средний прогноз, но и неопределённость, реализована двухшаговая калибровка:

- добавление алеаторической компоненты неопределённости;
- temperature scaling для корректировки ширины доверительных интервалов.

Качество неопределённости оценивается через `PICP95` и `MPIW95`.

### 9. Transfer learning

Отдельно проверяется перенос обучения на малую лабораторную выборку `boxcrete`. Модель сначала обучается на основном корпусе данных, затем дообучается на небольшой выборке.

Это позволяет проверить, насколько физически обоснованная модель полезна при нехватке данных.

### 10. Экстраполяция по возрасту

В проекте проверяется способность модели предсказывать прочность на возрастах, которые не были представлены в обучении. Это важный сценарий для бетона, так как прочность развивается во времени, а экспериментальные измерения часто доступны только на отдельных сроках.

### 11. Multi-output обучение

Дополнительно реализована модель, которая одновременно предсказывает:

- прочность бетона на сжатие;
- осадку конуса.

Этот эксперимент нужен для проверки того, помогает ли совместное обучение нескольким инженерным характеристикам.

### 12. HybridV3 и ансамбли

В финальной части реализована гибридная модель, объединяющая логарифмическую и экспоненциальную формы набора прочности. Также проверяются ансамбли и stacking-подходы.

HybridV3 используется как итоговая physics-aware модель с калиброванной неопределённостью.

### 13. Conformal prediction

Для получения формальных гарантий покрытия реализован conformal prediction. Этот подход позволяет строить интервалы прогноза, которые сохраняют заданный уровень покрытия без предположения о нормальности ошибок.

### 14. Inverse design

В финальной части решается обратная задача: подобрать состав бетонной смеси под заданную целевую прочность.

Модель оптимизирует рецепт с учётом:

- целевой прочности;
- возраста;
- физических ограничений;
- стоимости состава;
- доверительного интервала прогноза.

## Метрики

Для оценки качества используются:

- `MAE` — средняя абсолютная ошибка;
- `RMSE` — среднеквадратичная ошибка;
- `MAPE` — относительная ошибка в процентах;
- `R²` — доля объяснённой дисперсии;
- `NLL` — качество вероятностного прогноза;
- `PICP95` — покрытие 95-процентного интервала;
- `MPIW95` — средняя ширина 95-процентного интервала.

## Основные результаты

В проекте были получены следующие ключевые результаты:

- классические модели, особенно LightGBM и Random Forest, показывают сильное качество на обычном тестовом разбиении;
- физически обоснованные модели лучше проявляют себя при экстраполяции по возрасту;
- transfer learning заметно улучшает качество на малых лабораторных данных;
- GAN-цикл не дал значительного выигрыша над физически обоснованным генератором, так как дискриминатор оказался слабее генератора по точечной точности;
- калибровка неопределённости позволила получить надёжные доверительные интервалы;
- conformal prediction дал дополнительный способ строить интервалы с формальной гарантией покрытия;
- inverse design показал, что модель можно использовать не только для прогноза, но и для подбора состава смеси.

## Итог

Проект показывает, что для инженерных задач важно учитывать не только среднюю точность модели, но и физическую корректность, устойчивость к малым данным, способность к экстраполяции и качество оценки неопределённости.

Классические табличные модели дают сильный результат на данных, похожих на обучение. Физически обоснованные нейросетевые модели становятся полезнее там, где требуется переносимость, интерпретируемость поведения по времени и доверительные интервалы прогноза.
